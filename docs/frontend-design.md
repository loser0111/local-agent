## 一、设计目标与原则

### 1.1 设计目标

为 **local-agent**（本地 AI 编程助手）设计一套类 Claude Code 的桌面端界面，使开发者能够：

1. 并行管理多个 AI 编程会话
2. 在单一窗口内完成对话、代码审查、终端操作、文件编辑
3. 通过可拖拽面板自由组合工作区布局
4. 实时监控 AI Agent 的执行状态与工具调用

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **以对话为核心** | Chat 面板始终为默认主面板，其他面板围绕其展开 |
| **面板可组合** | 所有功能面板支持拖拽、缩放、分栏，布局按会话持久化 |
| **信息分层** | 三级视觉层级：主对话流 > 工具调用摘要 > 面板详情 |
| **暗色优先** | 默认深色主题，降低长时间编码的视觉疲劳 |
| **键盘友好** | 核心操作均有快捷键，支持纯键盘流转 |

## 三、整体布局框架

### 3.1 主工作区布局

```
┌──────────────────────────────────────────────────────────────┐
│  顶部工具栏 (TopBar) 高度: 48px                                │
├──────────┬───────────────────────────────────────────────────┤
│          │                                                   │
│  会话    │              面板容器 (PaneContainer)              │
│  侧边栏  │                                                   │
│  宽度    │   ┌─────────────────────┬─────────────────────┐   │
│  240px   │   │                     │                     │   │
│          │   │   对话面板          │   差异/终端面板      │   │
│          │   │   (ChatPane)        │   (可切换 Tab)       │   │
│          │   │                     │                     │   │
│          │   │                     │                     │   │
│          │   └─────────────────────┴─────────────────────┘   │
│          │                                                   │
└──────────┴───────────────────────────────────────────────────┘
```

### 3.2 尺寸规范

| 区域 | 尺寸 | 说明 |
|------|------|------|
| 顶部工具栏 | 高度 48px | 固定，不可折叠 |
| 会话侧边栏 | 宽度 240px，可折叠至 56px | 可拖拽调整宽度，范围 200~360px |
| 面板容器 | flex: 1 | 占据剩余空间 |
| 面板最小宽度 | 280px | 分栏时每个面板的最小宽度 |
| 面板最小高度 | 200px | 分栏时每个面板的最小高度 |

### 3.3 面板布局模式

面板容器支持以下布局，用户可通过拖拽自由组合：

| 布局 | 说明 |
|------|------|
| **单面板** | 仅对话面板占满工作区 |
| **左右分栏** | 对话面板（左，flex:2）+ 副面板（右，flex:1） |
| **上下分栏** | 对话面板（上）+ 副面板（下） |
| **三分栏** | 左对话 + 右上差异 + 右下终端 |
| **网格** | 2x2 网格布局 |

## 四、页面详细设计

### 4.1 主工作区布局页面（Workspace）

**路由**：`/`
**组件**：`Workspace.vue`

#### 布局结构

```vue
<template>
  <div class="workspace">
    <TopBar />
    <div class="workspace-body">
      <SessionSidebar />
      <PaneContainer>
        <ChatPane />          <!-- 常驻 -->
        <!-- 动态面板：Diff / Terminal / FileEditor / Plan / Tasks / Subagent / Preview -->
      </PaneContainer>
    </div>
    <NewSessionDialog v-if="showNewSession" />
    <SideChatDrawer v-if="showSideChat" />
  </div>
</template>
```

#### 顶部工具栏（TopBar）

| 元素 | 位置 | 说明 |
|------|------|------|
| 应用 Logo + 名称 | 左侧 | 点击可折叠侧边栏 |
| 项目选择器 | 左侧 | 下拉选择当前工作项目文件夹 |
| 模型选择器 | 中间 | 下拉切换模型（如 Claude Sonnet 4.5） |
| 权限模式选择器 | 中间 | Manual / Accept edits / Plan / Auto |
| 视图模式切换 | 右侧 | Verbose / Normal / Summary 三态按钮组 |
| 使用量按钮 | 右侧 | 展示上下文窗口和会话用量 |
| 设置按钮 | 最右侧 | 齿轮图标，跳转设置页 |

#### 交互说明

- 顶部工具栏固定，不随面板滚动
- 模型/权限模式可在会话中随时切换，切换后即时生效
- 侧边栏折叠时，Logo 区域变为汉堡菜单图标

### 4.2 会话侧边栏（SessionSidebar）

**组件**：`SessionSidebar.vue`

#### 布局结构

```
┌───────────────────────┐
│  [+] 新建会话          │  ← 顶部操作区（高度 56px）
├───────────────────────┤
│  筛选: [全部▾] [状态▾] │  ← 筛选区（高度 40px）
├───────────────────────┤
│  🔵 会话标题 A         │
│     活跃 · 2 分钟前    │  ← 会话列表项
│  🟢 会话标题 B         │
│     已完成 · 1 小时前  │
│  ⚪ 会话标题 C         │
│     归档 · 昨天        │
│  ...                   │
└───────────────────────┘
```

#### 会话列表项设计

| 元素 | 说明 |
|------|------|
| **状态指示点** | 🔵活跃（运行中）/ 🟢已完成 / 🟡等待输入 / 🔴错误 / ⚪归档 |
| **会话标题** | 首条用户消息摘要，超出截断 |
| **副标题** | 状态文字 + 最后活跃时间 |
| **项目标签** | 可选项，显示所属项目名 |

#### 交互说明

- **新建会话**：点击 `+` 按钮弹出 [新建会话弹窗](#412-新建会话弹窗newsessiondialog)
- **切换会话**：单击列表项切换，当前会话高亮
- **删除会话**：悬停显示删除按钮，二次确认后删除
- **筛选**：按状态（全部/活跃/已完成/归档）、按项目分组
- **折叠**：点击工具栏 Logo 或快捷键 `Ctrl+B` 折叠，折叠后仅显示图标

#### 数据结构

```typescript
interface Session {
  id: string
  title: string
  status: 'active' | 'completed' | 'waiting' | 'error' | 'archived'
  project: string
  lastActiveAt: number
  createdAt: number
  paneLayout: PaneLayout  // 该会话的面板布局配置
}
```

### 4.3 对话面板（ChatPane）

**组件**：`ChatPane.vue`
**说明**：核心面板，始终存在，不可关闭。

#### 布局结构

```
┌─────────────────────────────────────────┐
│  Chat                          [_][□][×]│  ← 面板标题栏
├─────────────────────────────────────────┤
│                                         │
│  [用户头像] 用户消息内容...              │
│                                         │
│  [AI 头像] AI 回复内容...                │
│   ┌───────────────────────────────┐    │
│   │ 工具调用: Read file (app.go)   │    │  ← 工具调用摘要
│   │ ✅ 完成 · 1.2s                 │    │
│   └───────────────────────────────┘    │
│                                         │
│  [用户头像] 用户追问...                  │
│  ...                                    │
│                                         │
├─────────────────────────────────────────┤
│  [📎][@][+]                              │  ← 输入工具栏
│  ┌─────────────────────────────────┐    │
│  │  输入消息... (Enter 发送)         │    │  ← Prompt Box
│  └─────────────────────────────────┘    │
│  [停止]                    [模型▾][发送] │
└─────────────────────────────────────────┘
```

#### 消息流设计

| 消息类型 | 展示方式 |
|----------|----------|
| **用户消息** | 左侧头像 + 气泡，支持 Markdown 渲染 |
| **AI 回复** | 左侧 AI 头像 + 流式输出文本，支持代码高亮 |
| **工具调用** | 折叠卡片，展示工具名、参数摘要、状态、耗时 |
| **系统消息** | 居中灰色小字（如"会话已开始"） |

#### 工具调用卡片

```
┌────────────────────────────────────┐
│ 🔧 Read file  ·  app.go            │
│ ✅ 完成  ·  1.2s                    │
│ [展开详情]                           │
└────────────────────────────────────┘
```

- 默认折叠，仅展示工具名 + 状态 + 耗时
- 点击展开查看完整参数和返回结果
- 状态色：运行中（黄色脉冲）/ 成功（绿色）/ 失败（红色）

#### Prompt Box（输入框）

| 元素 | 说明 |
|------|------|
| **附件按钮（📎）** | 上传图片、PDF 等文件 |
| **@提及按钮（@）** | 弹出文件选择器，@提及文件加入上下文 |
| **更多按钮（+）** | 技能、连接器、插件入口 |
| **文本输入区** | 支持多行，Shift+Enter 换行，Enter 发送 |
| **停止按钮** | AI 运行时显示，点击立即中断 |
| **模型选择器** | 快速切换模型 |
| **发送按钮** | 提交消息 |

#### 交互说明

- AI 回复采用 **流式输出**，逐字渲染
- 消息流自动滚动到底部，用户手动上滚时暂停自动滚动
- 工具调用在 **Verbose 模式** 完整展示，**Normal 模式** 折叠，**Summary 模式** 仅显示结果
- 代码块支持一键复制、查看差异（点击在 Diff 面板打开）

### 4.4 差异查看面板（DiffPane）

**组件**：`DiffPane.vue`
**快捷键**：`Ctrl+Shift+D`

#### 布局结构

```
┌──────────────────────────────────────────────────┐
│  Diff  +12 -3                    [Review code][_][□][×]│
├──────────────┬───────────────────────────────────┤
│  文件列表     │  差异详情                          │
│              │                                   │
│  ✅ app.go   │  - func old() {}                  │
│     +5 -2    │  + func new() {}                  │
│              │                                   │
│  ✅ main.go  │  @@ -10,3 +10,5 @@                │
│     +7 -1    │   ...                              │
│              │                                   │
└──────────────┴───────────────────────────────────┘
```

#### 功能模块

| 模块 | 说明 |
|------|------|
| **文件列表** | 左侧列出所有变更文件，显示增删行数统计 |
| **差异详情** | 右侧逐文件展示 unified diff，语法高亮 |
| **行内评论** | 点击任意行添加评论，提交后 Claude 读取并修改 |
| **Review code** | 右上角按钮，让 AI 审查当前 diff 并留下注释 |
| **按轮次切换** | 顶部可切换查看不同 turn 的差异（非仅最终状态） |

#### 交互说明

- 点击对话中的"查看差异"自动打开此面板
- 支持行内评论，`Ctrl+Enter` 批量提交
- 大文件差异支持折叠/展开文件块

## 七、状态管理与数据流

### 7.1 状态管理方案

使用 **Pinia** 进行状态管理，按模块拆分 Store。

### 7.2 Store 划分

| Store | 职责 | 核心 State |
|-------|------|-----------|
| `useSessionStore` | 会话管理 | `sessions[]`, `currentSessionId`, `createSession()`, `switchSession()` |
| `useChatStore` | 对话消息 | `messages[]`, `sendMessage()`, `stopGeneration()` |
| `usePaneStore` | 面板布局 | `panes[]`, `layout`, `openPane()`, `closePane()`, `movePane()` |
| `useSettingStore` | 设置 | `settings` 对象 |
| `useTerminalStore` | 终端 | `terminals{}` 按会话隔离 |

### 7.3 核心数据流

```
用户输入消息
    ↓
ChatStore.sendMessage()
    ↓
调用 Go 后端 (Wails Binding)
    ↓
流式接收 AI 响应 + 工具调用
    ↓
更新 ChatStore.messages
    ↓
触发 ChatPane 重新渲染
    ↓
工具调用完成 → 更新 ToolCallCard 状态
    ↓
代码变更 → 通知 DiffPane / FileEditorPane
```

### 7.4 前后端通信

通过 Wails 自动生成的绑定（`frontend/wailsjs/go/main/App.js`）调用 Go 方法：

| Go 方法 | 前端调用 | 说明 |
|---------|---------|------|
| `Greet(name)` | `Greet(name)` | 示例方法 |
| `CreateSession(config)` | `CreateSession(config)` | 创建会话 |
| `SendMessage(sessionId, msg)` | `SendMessage(sessionId, msg)` | 发送消息 |
| `GetDiff(sessionId)` | `GetDiff(sessionId)` | 获取差异 |
| `RunTerminal(sessionId, cmd)` | `RunTerminal(sessionId, cmd)` | 执行终端命令 |

## 八、路由设计

```javascript
// router/index.js
const routes = [
  {
```

面板间切换通过 **PaneStore** 管理，不使用路由切换。
