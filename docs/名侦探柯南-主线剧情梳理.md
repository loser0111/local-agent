## 一、统计口径（步骤 1）

### 1.1 统计范围
- **主体**：电视动画（TV 版）剧集。
- **不含**：剧场版、OVA、特别篇单独计数；如与主线强相关的剧场版会在阶段说明中作为"关联事件"附注，但不计入集数区间。
- **动画原创集**：原则上按"是否含主线要素"判定纳入，与漫画改编集一视同仁。

### 1.2 集数编号基准
- **以日本原版（日版）集数为准**，标题亦以日版为准。
- **国内拆分版差异**：中国内地视频平台（爱奇艺/腾讯/优酷等）引进时，将部分 1 小时 / 2 小时特别篇拆分为 2 集播出，导致编号自中段起与日版逐渐错位、总集数多于日版。
  - 因此凡涉及特别篇或中后期集数，将在逐集条目中以「日版第 X 集（≈国内拆分版第 Y 集）」形式**注明对应关系**；无把握的对应关系会标注"待核"。
- 首集「云霄飞车杀人事件」日版与国内版均为第 1 集，为编号起点参照。

### 1.3 "主线"判定要素（满足任一即可能入选）
1. **黑衣组织登场与行动**：琴酒/伏特加/贝尔摩德等组织成员的出场、交易、暗杀、追查等。
2. **APTX4869 及解药相关**：药物线索、解药（试制品/临时解药）研发与服用、身体复原情节。
3. **身份暴露危机**：柯南/灰原哀真实身份的暴露风险或被识破的悬念。
4. **情报机关对决**：FBI、CIA、日本公安与组织的对抗、卧底与反卧底暗战。
5. **关键人物专题**：赤井秀一、安室透（波本/降谷零）、贝尔摩德、基尔（水无怜奈）、BOSS（乌丸莲耶）、朗姆等核心人物的身份揭示与线索推进。
6. **核心事件/物件**：板仓卓（软件设计师遇害案）、羽田浩司案及其遗留线索等重大主线谜团。

### 1.4 关联强度分级（用于②③步标注）
- **核心主线（强）**：直接推进组织线、身份线、机关对决或关键人物身份的重大集数。
- **准主线（中）**：含主线要素但以铺垫/呼应为主（如新一登场、黑衣组织仅末尾露面）。
- **边缘提及（弱）**：仅一句台词或彩蛋式触碰主线，可视需要单列附注。

### 1.5 逐集记录字段（供③④步使用）
| 字段 | 说明 |
|---|---|
| 日版集数 | 如 001、128、345 |
| 国内拆分版集数 | 如有差异则注明，否则同号 |
| 标题 | 日版标题（可附中文常用译名） |
| 关联强度 | 核心主线 / 准主线 / 边缘提及 |
| 主线要点 | 该集交代的具体主线内容（组织行动、人物、线索等） |
| 所属阶段 | 见②步的阶段划分 |
